# chavdaujjval.github.io

My portfolio, live at https://chavdaujjval.github.io

Built from the [Magic UI portfolio template](https://github.com/magicuidesign/portfolio) (MIT) with Next.js, Tailwind and shadcn/ui. Every push to `main` rebuilds the site with GitHub Actions (`.github/workflows/deploy.yml`).

- Edit your details in `src/data/resume.tsx`.
- Run locally: `npm install`, then `npm run dev`.
- Build the static site into `out/`: `npm run build`.
